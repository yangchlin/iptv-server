# 📺 IPTV EPG 智能管理系统

基于 FastAPI 的 Docker 化 EPG 电视节目管理系统，专为飞牛 NAS (fnOS) 设计。

## 🚀 快速开始

### 1. 上传到飞牛

将整个 `iptv-server` 文件夹上传到飞牛 NAS。

### 2. 构建镜像

```bash
cd /path/to/iptv-server
bash build.sh
```

### 3. 启动容器

```bash
docker compose up -d
```

启动后访问：**http://飞牛IP:5673**

## 📂 目录结构

```
/vol1/1000/Docker/IPTV/
├── json/        # 下载的 JSON 节目数据
├── xml/         # 生成的 EPG XML 文件
├── m3u/         # M3U 播放列表文件
├── logs/        # 运行日志（保留7天）
└── data/        # 配置数据（频道列表、设置等）
```

## ✨ 功能特性

### 📊 仪表盘
- XML 直链（可复制到其他软件）
- 一键下载（今天+明天+后天）
- 下载过往节目单（过去6天）
- 生成 XML 文件
- 下载/合并外部 EPG 源
- 清理过期文件
- 实时下载进度（暂停/继续/停止）

### 📋 频道管理
- 拖拽排序
- 添加/编辑/删除频道
- 自动检测日期格式并替换为 `{date}` 占位符
- 启用/禁用频道（禁用的不下载）
- 分页查看（10~5000条/页）
- 导入/导出频道列表
- 一键替换链接域名
- 内置70个默认频道

### 🌐 外部 EPG
- 管理外部 EPG 源（添加/编辑/删除）
- 自动检测 XML 规则（112114 / 51zmt）
- 搜索外部 EPG 中的频道
- 提取节目信息并合并到本地 XML
- 统一提取并合并

### 📺 M3U 管理
- 上传/直链下载 M3U 文件
- 查看和编辑 M3U 内容
- 手动匹配频道节目单（下拉选择）
- 自动同步 tvg-id 和 tvg-name
- 保存后导出下载

### 🔗 映射/代理
- 端口映射（旧域名→新域名/地址）
- 302 代理服务（外网访问内网 IPTV 源）
- 支持多条代理规则
- 代理端口自定义

### ⚙️ 系统设置
- 定时任务时间配置（默认12:00）
- 定时任务启用/禁用
- 代理端口配置
- 共享目录路径（输出 XML 到其他目录）

### 📝 日志
- 每日日志文件（保留7天）
- 在线查看
- 下载到本地

## 🔧 API 接口

| 接口 | 说明 |
|------|------|
| `GET /api/xml` | 获取 EPG XML |
| `GET /api/xml/download` | 下载 XML 文件 |
| `GET /api/status` | 系统状态 |
| `GET /api/channels` | 频道列表 |
| `POST /api/channels` | 添加频道 |
| `PUT /api/channels/{idx}` | 更新频道 |
| `DELETE /api/channels/{idx}` | 删除频道 |
| `GET /api/epg/sources` | 外部 EPG 源列表 |
| `GET /api/epg/channels?keyword=` | 搜索 EPG 频道 |
| `GET /api/proxy/{path:path}` | 代理服务（302重定向） |

## ⚠️ 注意事项

1. **换行符**：所有配置文件使用 Linux (LF) 换行，切勿在 Windows 记事本编辑
2. **端口映射**：容器对外端口 5673，内部端口 80
3. **首次启动**：会自动初始化70个默认频道和2个外部EPG源
4. **数据持久化**：所有数据保存在 `/vol1/1000/Docker/IPTV/` 目录
5. **外网访问**：需在路由器上开放 5673 端口
6. **代理功能**：用于解决外网无法访问内网 IPTV 源的问题

## 🐛 故障排查

- 容器无法启动：检查 docker logs，确认端口 5673 未被占用
- XML 下载卡顿：映射/代理页面中配置代理规则
- EPG 下载失败：检查网络连通性，外部源可能被屏蔽
